# AER v1 픽셀 2-entry CIFAR10-DVS 비교

## 1. 비교 조건

- 입력: CIFAR10-DVS `airplane_0` 전체 178,165이벤트
- 부하: 1ms 이동 구간 최대 1GEPS가 되도록 1297.016861배 재생
- 센서: 128×128픽셀
- 픽셀 입력 저장: 픽셀당 FIFO 2-entry
- 공통 구조: 2×2 타일, 4×4타일 뱅크, 동일 중재기·버퍼·16비트 링크
- 시간 기록: 외부 링크의 패킷 첫 워드 수신 시각
- 차이: `ENABLE_BINNING=1` 또는 `0`
- 도구: 로컬 Vivado 2024.1 XSim 기능 시뮬레이션
- 합성: 수행하지 않음

같은 주파수의 비닝과 무비닝은 같은 클록에 같은 이벤트를 입력했다. 입력 벡터 SHA-256은 100MHz에서 `83a1815f...d759`, 200MHz에서 `8e14c6e0...1376`으로 각각 일치한다.

손실은 픽셀 FIFO가 가득 찬 동안 들어온 이벤트와 같은 사이클에 같은 픽셀·극성으로 중복된 이벤트를 합해 계산한다. 저장된 이벤트는 시뮬레이션 종료 전에 모두 읽혔다.

## 2. 구현 규약

각 픽셀은 `head`와 `tail` 두 슬롯을 가진다.

1. 첫 이벤트는 head에 저장한다.
2. head를 읽기 전에 다음 이벤트가 들어오면 tail에 저장한다.
3. 타일 handshake 때 각 활성 픽셀의 head 한 개만 제거한다.
4. tail이 있으면 head로 올려 다음 readout을 기다린다.
5. pop과 새 이벤트가 같은 클록에 발생하면 두 동작을 모두 처리한다.
6. 두 슬롯이 모두 찬 상태에서 추가 이벤트가 들어올 때만 손실로 센다.

같은 사이클에 동일 픽셀의 ON과 OFF가 동시에 들어오면 순서를 알 수 없으므로 기존 규약처럼 ON 하나를 저장하고 나머지 하나를 손실로 센다.

## 4. 1-entry 대비 개선

| 주파수 | 방식 | 1-entry 손실률 | 2-entry 손실률 | 감소 |
|---|---|---:|---:|---:|
| 100MHz | 비닝 | 33.88% | 20.68% | **13.20%p** |
| 100MHz | RAW8 | 34.49% | 21.36% | **13.13%p** |
| 200MHz | 비닝 | 18.94% | 10.07% | **8.87%p** |
| 200MHz | RAW8 | 19.04% | 10.16% | **8.88%p** |

픽셀당 저장 공간을 한 칸 늘린 효과가 비닝 자체의 효과보다 훨씬 컸다. 추가 상태량은 픽셀마다 tail valid 1비트와 polarity 1비트이므로 128×128 기준 논리적으로 32,768비트다. 실제 면적과 전력은 합성 후 확인해야 한다.
