# 손실형 2×2 비닝 Python 검증

## 1. 목적

RTL을 수정하기 전에 다음 가설을 Python 구조 모델로 먼저 확인했다.

> 2×2 타일에서 같은 극성의 이벤트가 세 개 또는 네 개 발생하면 모두 동일한 BIN으로 표현한다. 세 이벤트의 빠진 픽셀 위치를 버리는 대신 BIN4와 함께 패킹하여 링크 처리율을 높이고, 고부하에서 버퍼 넘침으로 사라지는 이벤트를 줄인다.

이 문서의 수치는 구조 탐색용 Python 모델 결과다. 이후 같은 정책을 Verilog RTL로 구현해 XSim과 Vivado 합성까지 수행했으며, 별도 결과는 [손실형 RTL·XSim·합성 검증](AER_손실형_RTL_XSim_합성_검증.md)에 정리한다.

## 2. 손실형 표현

| 2×2 타일 상태 | 무손실 방식 | 손실형 방식 |
|---|---|---|
| 한 극성 4개 | 극성 1비트 BIN | 극성 1비트 BIN |
| 한 극성 3개, 나머지 없음 | 극성+빠진 위치 GROUP3 | 극성 1비트 BIN |
| 두 개 이하 또는 극성 혼합 | RAW8 | RAW8 |

손실형 수신기는 세 이벤트와 네 이벤트를 구분하지 않고 네 픽셀 모두에 같은 극성을 복원한다. 따라서 3-of-4 타일마다 가짜 이벤트가 한 개 추가된다.

3-of-4와 4-of-4는 동일한 극성 1비트 토큰이므로 한 워드에 함께 패킹할 수 있다. 혼합 뱅크 패킷에는 `유효 타일 비트맵`과 `BIN 타일 비트맵`을 넣고, BIN이 아닌 타일은 RAW8로 전송한다. 손실형 패킷의 정확한 워드 수가 RAW 전송보다 작을 때만 적용하며, 이득이 없으면 RAW로 복귀한다.

## 3. 비교 조건

- 데이터: CIFAR10-DVS `airplane-0`, 178,165이벤트
- 부하: 기존 1ms 이동 구간 peak 1GEPS 실험과 같은 1297.016861배 재생
- 센서: 128×128
- 타일: 2×2픽셀
- 뱅크: 4×4타일, 즉 8×8픽셀
- 픽셀 버퍼: 픽셀당 2개 이벤트
- 출력: 16비트, 클록당 한 워드
- 클록: 100MHz, 200MHz
- 공통 조건: 같은 입력 이벤트, 버퍼 깊이, 뱅크 선택 순서와 링크 폭

비교 방식은 다음 네 가지다.

1. `raw`: 기존 행 단위 RAW8 전송
2. `raw_bank`: 정보를 줄이지 않고 RAW8 두 타일을 한 워드에 넣는 뱅크 패킹
3. `lossless`: GROUP3와 BIN4를 구분하는 무손실 혼합 패킷
4. `lossy`: 3-of-4와 4-of-4를 같은 BIN으로 처리하는 손실형 혼합 패킷

`전체 이벤트 오류율`은 `(버퍼에서 드롭된 실제 이벤트 + 손실형 복원으로 추가된 가짜 이벤트) / 원본 이벤트`로 정의했다. 드롭만 집계한 `이벤트 손실률`과 구분한다.

### 100MHz

|---|---:|---:|---:|---:|---:|---:|
| 기존 행 RAW | 140,399 | 21.20% | 0% | 21.20% | 0.7206 | 0.1388GEPS |
| RAW 뱅크 패킹 | 157,648 | 11.52% | 0% | 11.52% | 0.6069 | 0.1648GEPS |
| 무손실 혼합 | 158,125 | 11.25% | 0% | 11.25% | 0.6044 | 0.1654GEPS |
| 손실형 혼합 | 158,645 | 10.96% | 2.44% | 13.40% | 0.6023 | 0.1660GEPS |

기존 행 RAW와 비교하면 손실형 구조는 모델상 유효 링크 처리율이 19.65% 높고, 드롭률은 10.24%p 감소했다. 가짜 이벤트까지 더한 전체 이벤트 오류율도 21.20%에서 13.40%로 7.80%p, 상대적으로 36.78% 감소했다.

## 5. 해석과 한계

손실형 구조는 기존 행 RAW 기준으로는 가짜 이벤트를 감수하고도 전체 오류를 줄였다. 따라서 “일부 공간 정밀도를 의도적으로 포기해 고부하의 무작위 드롭을 줄였다”는 가설은 이 비교 범위에서 성립한다.

다만 손실형 비닝 자체가 가장 큰 개선 원인은 아니다. RAW 뱅크 패킹만 적용해도 100MHz 드롭률이 21.20%에서 11.52%로 크게 감소했다. 또한 RAW 뱅크 패킹과 비교하면 손실형 구조는 유효 링크 처리율을 0.77% 높였지만 전체 이벤트 오류율은 1.89%p 증가했다. 200MHz에서도 처리율 증가는 0.14%에 그치고 전체 오류율은 1.04%p 증가했다.

따라서 자소서에서는 다음 범위를 지켜야 한다.

- 비교 기준을 `기존 행 단위 RAW 전송`으로 명시한다.
- 제안 구조를 `손실형 비닝만`이 아니라 `손실형 비닝과 혼합 뱅크 패킹, 비용 기반 RAW 복귀를 결합한 구조`라고 쓴다.
- `손실률`은 버퍼 드롭률인지, 가짜 이벤트까지 포함한 전체 오류율인지 구분한다.
- 수치는 Python 구조 모델 결과이며 RTL 구현이나 합성 결과라고 표현하지 않는다.
